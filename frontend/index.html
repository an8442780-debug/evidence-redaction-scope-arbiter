How it works

  1. Publisher commits a bounded public document.
  2. A reviewer proposes paragraph ranges and freezes the case.
  3. GenLayer validators independently assess the same frozen inputs.
  4. Only APPLY, REJECT, or fail-closed UNRESOLVED can become terminal state.
